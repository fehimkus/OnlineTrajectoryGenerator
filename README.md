# OnlineTrajectoryGenerator
online trajectory generator to generate position and velocity values for motion control blocks

## 🚧 Under construction

This project is at an early stage and is **not usable yet**. The code is
incomplete, does not compile in its current state, and the API will change.

Current work: brake distance calculation in `src/TrajectoryGenerator.cpp`.
Profile generation and the accelerate / cruise / brake decision are not
implemented yet.
